# 训练房（2026-10-28）

## 入口与内容

在 Unity 打开 Boot 场景并 Play，输入名字 → 进入 → 训练房。也可选择原有的 2v2 对战；此时才连接公网大厅并进入公共房间。

训练房由本机运行同一套 NGO 权威战斗逻辑，只监听回环地址，使用系统分配端口；无需云端登录、不占公共房间名额，也不需要上传服务器文件。它是个人调试场，不支持其他机器加入。

- 左侧从上到下：狙击枪、手枪、AK、匕首。训练中可直接拾取另一把武器替换当前装备。
- 上方两排：绳索收缩、绳索延长、护盾、冲刺装置、炸弹、弹性强化、血包、问号盒。状态道具立即生效；冲刺与炸弹保存在身上，按 E 使用，新使用道具覆盖旧的。
- 所有拾取物两秒刷新，固定类型。
- 两个红队静止靶子供命中测试，倒地两秒后恢复。
- “增加队友”最多添加三人，“移除队友”逐个移除。队友无 AI、不会走路或开枪、不会抢道具；仍有碰撞和绳索物理，可以被拖动。
- 无对局计时与自动结算。“重置训练”恢复站位、血量、装备、道具和状态；“返回”清理本机网络，返回模式选择。

控制沿用 WASD、鼠标瞄准/左键攻击、E 使用道具。训练中死亡可用“重置训练”恢复。

## 实现边界

训练地图在 TrainingMap.cs 独立生成，不改动设计同学的 GameConfig.json 关卡或枪械数值。TrainingRuntime 管理本地主机、静止角色和清理；BattleWorld 复用拾取、战斗和绳索逻辑，训练分支取消终局并支持换枪。原 2v2 对战仍使用云端服务器与原规则。

本次交付为源码，无新 exe、服务端构建或压缩包。已有 exe 不包含本次训练入口。

## 验证

自动化测试覆盖训练物品完整性、本地主机启动、无需后台账号、三名队友上限及静止输入、换枪、冲刺消费、靶子恢复、重置、退出与再次进入。最终测试结果见交付回复及 logs/unity-editor-tests.xml。图形界面与手感仍需在 Unity Play 中检查。
