# 角色生命固定，不再随武器变化

后续第5条已将出生/复活装备改为默认匕首；固定生命规则继续生效，见[第5、6条说明](ITEM_CHANGE_05_AMMO_06_MAIN_MENU.md)。文末“第5条未实施”为本次修复当时的记录。

2026-11-02用户修正：生命总值由角色配置决定，拿枪、换枪、持有匕首均不应改变当前生命和生命上限。本规则取代此前所有“武器决定生命上限”的方案。

## 修复结果

- 生命上限统一取 `GameConfig.baseHealth`。保留用户当前设置 **100**，没有改回此前的30。
- 出生/复活为100/100；满血换任意武器仍为100/100；受伤至75/100后换狙击、手枪、AK、匕首仍为75/100。
- 换武器只更换武器并处理攻击冷却，不再写入当前生命或生命上限，也不改变护盾。
- 受伤、血包和复活仍按原规则改变当前生命；血包不能超过角色上限。固定的是生命上限与武器无关，并非角色不再受伤。
- 数值编辑器保留唯一的 **角色生命上限（HP）**，移除每种武器的生命上限字段。武器拾取卡不再显示生命上限。
- 删除武器配置中的`maxHealth`及对应代码字段；旧JSON中的遗留字段会被忽略，不再参与游戏。友伤、物资概率、伤害/射速、现有地图及用户新建编辑场景均保留。

## 使用与验收

停止Play，等待Unity编译完成。在 **Bound Shoot → 数值编辑器**中点击“重新载入”，确认“角色生命上限（HP）”为100，再重新Play。已有Play会话中的生命值不会被热修正。

在训练房依次拾取四种武器：上限都应保持100。受伤后重复换枪，当前血量也应保持不变；拾取血包仅增加配置的恢复量，上限仍为100。死亡后复活恢复到100/100。

此前第2条中的18/30/30/45武器生命表、换狙击截断血量、换匕首提高上限，以及旧截图里的武器生命标签均已废止。其他武器数值保持用户当前配置。
