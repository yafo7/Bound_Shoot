# main 交付说明

本次将此前开发迭代整理为 0.3.0 源码交付，面向接手开发、配置与测试的同学。Unity 版本为 2022.3.62f3，后端需要 Node.js 24+。项目运行、构建和目录入口以根目录 README 为准。

## 功能变更

- 公网大厅支持名字登录、创建／加入房间、地图选择、2v2–4v4、AI 补位、准备和热身，由房主开始正式对战。新增数据库迁移 004。
- 对战以全部热点的平均热度为胜利条件，取消对局限时，保留开场倒计时。新增占点地图和选图预览，救助倒地队友、拖拽尸体与全队团灭等待共用权威逻辑。
- 角色生命上限固定，武器提供有限弹药，耗尽恢复小刀。一个武器位加三个道具位，E 切换，左键使用。
- 白、蓝、红随机物资池支持关卡配置与按时原地换新。加入烟雾弹、燃烧弹、火箭炮和大宝剑。冲刺道具调整为短时提速，同时增强拖拽拉力。
- 数值编辑器可配置武器、弹簧、投掷物、提速及团灭等待。当前启用统一团灭复活 20 秒，各地图原等待值保留，关闭覆盖后使用地图值。
- 更新像素战斗 HUD、音乐、阵营颜色击杀提示、Tab 战绩以及 MVP 和全员战绩结算。
- 构建脚本增加 Mac Mono 通用客户端，支持 Intel x86_64 和 Apple ARM64。Windows、LinuxServer 和 QA 构建入口保留。

## 数据和部署

当前源码默认指向 `123.207.238.56:3000`。2026-11-04 已部署匹配 20 秒团灭等待的 Linux 战斗服和共享配置。此次 Git 提交是源码同步，运行中的服务状态需单独检查。

新 clone 包含 Unity 源码、资源、配置、后端、部署脚本、需求原文和文档中的验证截图。Unity 缓存、构建包、本地日志、数据库、真实环境文件以及 Bitvise 登录配置由 Git 忽略。构建文件需按 README 重新生成，生产环境的 `.env` 和数据库在服务器独立维护。

## 验证与限制

本次提交前共享配置校验、TypeScript 编译和后端 6 项测试均通过。首次在沙箱内运行的 3 项 HTTP 测试因回环连接 EACCES 失败，在允许回环连接的环境重跑后全部通过。
