# 移动朝向、三倍生命与拾枪提示

2026-10-30。本轮承接森林/UI v3，按用户反馈修正，交付源码并提交远端Git；不构建客户端/服务器，不更新云端。

## 修复与行为

身体原先直接用瞄准角度选择正面/侧面/背面，因此向右走而鼠标在角色上方时仍是背面步行动画。现在身体根据实际位移选方向：上走背面、下走正面、右走侧面、左走镜像侧面。静止时保留最后朝向，绳索拖动同样驱动步行动画。枪仍独立指向鼠标，枪械镜像、握点与绘制层级按瞄准计算，避免侧走向后射击时枪倒置。沿用原12fps六帧循环及停步宽限，不重置原有动画节奏，不改PNG。

生命修改直接保存到GameConfig，避免运行时重复乘倍数；所有角色、AI与训练靶子共用配置：

| 状态/武器 | 原最大生命 | 新最大生命 |
|---|---:|---:|
| 空手/出生/复活 | 3 | 9 |
| 狙击枪 | 1 | 3 |
| 手枪 | 3 | 9 |
| AK | 3 | 9 |
| 匕首 | 5 | 15 |

伤害、攻速、复活五秒及180秒计时不变。换枪仍不回血，当前生命截到新上限；复活恢复空手9血。血包仍回1点、护盾仍加1点，避免顺带更改原道具规则。血量变多会增加承伤次数，但不能保证每局时长恰好三倍；狙击状态3血仍可能被4伤狙击一枪击倒，保留原武器差异供后续调平衡。

右上红心每行5颗，15血完整显示为三行，不截断到12颗、不横向溢出。生命与实际HP一一对应；灰心表示已失去的HP。

右下武器框改为临时拾枪卡：空手隐藏，换成不同武器时出现，显示图片、名称、伤害、射程、开火间隔、弹速/近战、最大生命，3秒后隐藏。连续换枪更新内容并从头计时；同枪不重复触发；死亡/离开清除。使用非缩放时间，不因加速测试改变三秒显示长度；设置/红心重绘也不会重新计时。持有E道具时另外显示小道具栏，武器卡隐藏不影响使用道具。
