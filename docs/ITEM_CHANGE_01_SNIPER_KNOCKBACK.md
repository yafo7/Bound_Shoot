# 道具修改第1条：狙击命中击退

需求来源：`new needs/道具修改意见.md`第1条。本条已获用户确认；下文保留第1条交付时的范围和验证记录。后续第2条的数值及编辑器以[第2条说明](ITEM_CHANGE_02_BALANCE_EDITOR.md)为准。

## 本条规则与实现

- 狙击命中沿子弹飞行方向对目标刚体施加一次冲量，由权威端执行，再通过现有位置快照同步。
- 普通弹丸碰撞与枪口前的近距离命中都处理；子弹记录发射时的击退参数，射手发射后换枪不改变在途子弹的效果。
- 护盾吸收伤害也击退；复活保护中的命中不造成伤害或击退；致命命中在倒地状态重置之后仍施加冲量，推动身体。
- 已倒地身体不会被后续子弹继续击退，沿用当前只命中活角色的规则；致命那一发正常推动身体。
- 真人、AI与训练靶子共用规则；墙体碰撞和绳索牵引继续生效，不直接修改位置、不忽略碰撞。
- 其他武器击退默认为0。本条没有开启友伤，没有修改血量、伤害、射速、物资点、弹药或出生武器。

## 如何调整

文件：`unity-client/Assets/BoundShoot/Resources/GameConfig.json`。

在`weapons`内`kind: 1`（狙击枪）条目调整`knockbackImpulse`。初始值为 **6**，单位是物理冲量；质量1的角色受到命中时增加约6单位/秒的沿弹道速度，后续位移受移动制动、阻力、障碍与绳索影响，因此不是固定击退6米。

- 0：关闭该武器击退。
- 更大的正数：更强冲量；小步调整并检查贴墙、绕角与冲刺叠加。
- 必须为有限非负数；配置检查脚本会拒绝负数等非法值。
- 当前未填写此字段的旧武器配置按0处理，保持兼容。

停止Play后改值，再重新Play加载。第2条才增加可视化数值编辑器，本条不提前实现。

## 验收步骤

1. 打开Boot场景，进入训练房，拾取狙击枪，射击靶子；检查靶子沿弹道移动。
2. 近距离枪口覆盖靶子时攻击，同样应击退。
3. 有护盾目标命中仍后移；复活保护期间不后移；致命命中身体仍后移。
4. 在墙前、绳索拉紧时观察位移，应被墙挡住或受伙伴牵制。
5. 换为手枪/AK/匕首，确认未新增击退；伤害、生命和其他规则保持原值。
