# 三道具背包与E切换、左键使用

2026-11-02用户确认：武器之外最多存3件道具，共4格。此说明取代之前“血包/护盾/绳索拾取即生效、E直接使用单个持有道具”的规则。

## 操作与容量

- 第1格固定显示当前枪械或默认匕首；第2–4格各存一件道具。
- E循环切换：武器 → 道具1 → 道具2 → 道具3 → 武器，跳过空格。没有道具时保持武器位。
- 选武器时左键攻击，保留枪械/匕首原有按住攻击和攻击间隔。选道具时左键按下一次使用一件，不同时开枪。
- 使用后该道具消耗，选择自动回到武器；需要松开左键再按下才能继续攻击，避免长按同一次点击时自动开枪或连用道具。
- 同类道具可以重复携带，每件独占一格，不叠加为一个数量格。使用后留下空格，下一次拾取填入最前面的空格。
- 满3件时不再拾取道具，不替换已有道具；地面物资继续保留，刷新倒计时也不会提前启动。其他有空位的玩家仍可拾取。
- 枪械拾取/补弹仍使用独立的武器位，不占3个道具位。选中道具时踩枪只更新武器位，仍由E切换回武器。

## 道具行为

血包、护盾、冲刺、炸弹、绳索收缩、绳索延长、弹性强化都先进入背包，左键使用后才产生原有效果。问号盒拾取时由权威端抽取一种实际道具存入背包，不会立即发动效果。

道具效果的数值和范围不变：血包/护盾受当前上限约束；冲刺沿移动方向，没有移动时沿瞄准方向；炸弹仍放在使用时的身体位置。绳索类持续时间从使用时开始计算。满血使用血包或满盾使用护盾仍会消耗该件道具，不会突破上限。

死亡清空全部道具，复活/训练重置/对局再战恢复到默认匕首及空背包，选择回到武器位。固定角色生命100、有限枪械弹药、友伤及三级物资概率均保留。

## 显示与AI

右下HUD显示4格图标和名称，用高亮区分当前选中格，空格显示“空”；保留持续弹药行以及3秒拾枪数值卡。原来的单个E道具条被四格背包取代。

AI也使用最多3件的背包。受伤时使用血包、缺盾时使用护盾；炸弹和冲刺按距离/移动条件使用，绳索道具在交战时使用。使用当帧停止攻击，之后回到武器；训练伙伴和靶子保持无AI、不主动使用。

## 实现与输入保护

`NetPlayer`使用三个服务器写入的网络道具字段与当前选中格；`SubmitInput`携带E和左键按下事件。按下/松开事件立即发送，不等待常规移动采样间隔，避免短按丢失。保留所有权、输入序号、输入世代、存活和战斗阶段检查。

`BattleWorld.TryCollectItem`负责容量和入库；`TryUseSelected`负责权威使用、消费与回武器，武器攻击必须选中武器位。满背包不会触发地面物资刷新。`BotController`和`ForestFlow`同步更新。

## 验收步骤

1. 停止Play、等待编译，再进入训练。初始只有第1格匕首，三个道具格为空。
2. 受伤后踩血包，确认血量暂不恢复、血包进入格子；按E选中，再左键使用，应回血并回到武器位。
3. 存入3件道具，包括同类型两件；再次踩道具应留在地上。用掉一件后即可拾取。
4. 多次按E，确认跳过空格并循环；选中炸弹/冲刺等左键使用，确认没有同时开枪。使用时长按左键，确认松开前不自动攻击。
5. 死亡/复活或重置训练，确认背包清空；联机观察选择、道具消费和效果同步。
