# 基础版交付状态 · 2026-10-27

当前是供继续设计内容的 **v0.1 基础原型**，不是所有需求均已通过正式验收的发行版。

## 已实现

- Unity 2022.3 工程、Windows 开发构建、独立游戏服务器启动入口。
- Node.js/TypeScript/Express/ws、SQLite自动迁移、bcrypt账号、签名短期Access Token、可撤销且轮换的Refresh Token。
- 登录注册、外观、大厅、房间号、座位链、准备、房主迁移、地图注册表与选择、启动/容量/端口管理。
- 每局独立服务间密钥、一次性连接票据核销、服务器批准连接，所有权对应账号；客户端不能上传队伍、血量或击杀。
- 服务器移动与碰撞、四种武器、武器锁定、弹丸与近战、护盾、生命、死亡、尸体物理、相邻座位绳链。
- 绳索实际作用于刚体；按障碍折线路径总长度施力；状态收缩/延长/双方弹性强化。
- 状态立即使用、单槽E道具、覆盖、冲刺、3秒炸弹、血包、可配权重问号盒、补给刷新。
- 区域内连续5秒复活、离开重置、空手3血恢复、短暂保护；全灭、180秒计时与平局比较。
- 权威结算、击杀/死亡/实际伤害、数据库累计战绩、结算返回房间并再次开战。
- 断线输入超时、实体保留、20秒宽限后死亡、重新核销票据接回原实体；房间失联释放。
- 无界面服务器跳过字体、相机和绳索渲染，不把Linux服务端运行依赖在客户端字体/着色器上。
- 设计交接、API、原始需求、Windows启动与构建脚本、Linux构建入口、systemd/nginx/环境变量模板。

## 尚未完成或未充分验证

1. **跨两台电脑、真实四人手感与公网联机尚未验收。** 已验证同一电脑上的真实四客户端/独立服务器，不能据此宣称多机网络通过。
2. **Linux二进制与Ubuntu实机部署未执行。** 本机编辑器仅有Windows/WebGL模块，缺Linux Dedicated Server模块；需要安装同版本模块，并提供实际Ubuntu机器才能构建/部署验收。
3. 3v3/4v4房间、座位和多段链代码已接入，尚未做六/八客户端运行验证。
4. 绳索只支持轴对齐矩形掩体；最短可见路径会在绕柱等长两侧切换，没有持续缠绕拓扑。复杂绕行、冲刺、拖尸、多段拉扯的长期稳定性仍需人工测试。
5. 绳索为弹性软约束，极端冲刺时可暂时超过标称长度；没有硬位置瞬移。需后续调手感和伸长容许值。
6. 复活、所有道具组合、长时间180秒回合、丢包/高延迟、断线恢复全场景尚未逐项完成端到端回归；已有实际逻辑与部分规则/物理测试，不能视为全部人工验收。
7. 当前15Hz实体视觉快照采用可靠JSON分片，未做增量压缩、移动预测或延迟补偿；需要测量流量再优化。
8. 美术是占位几何体，尚无正式角色动画、音效、最终地图美术。当前4种外观主要由颜色与装饰区分。
9. 只提供完整数据化Arena_01；后续岩浆、传送带、旋转地图未制作。新增环境机制需要追加服务器逻辑。
10. 部署模板已提供，云服务、TLS证书、实际防火墙规则和日志轮转尚未配置。
