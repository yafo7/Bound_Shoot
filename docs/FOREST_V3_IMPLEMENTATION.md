## 在 Unity 中查看

打开工程 `D:/workshop/developer_learn/Unity_Hub/Project/Bound_Shoot`，运行 `Assets/BoundShoot/Scenes/Boot.unity`。现有菜单 **Bound Shoot → Play Vegetable Demo** 同样进入这个流程。

1. 标题页点击「进入游戏」。
2. 同屏输入名字、选择八种蔬果之一，确认进入。
3. 选择训练房、本地AI对战或联机对战。
4. 等待房选择2v2、3v3或4v4；点击空位/AI位置换座，座位顺序对应相邻绳链。
5. 房主点击开始，中央倒计时后进入战斗，结算可再来一局。

WASD移动，鼠标瞄准/左键攻击，E使用持有道具；踩不同枪自动换枪。数值仍以GameConfig为准，没有修改同学的武器伤害、射程、攻速或最大生命。

训练房按人数创建本人、静止伙伴和靶子；伙伴没有自主AI，可以被绳子拖动。场内仍可增加/减少伙伴、重置。靶子是练习对象，倒地后两秒回靶位；正式队友适用五秒规则。

本地AI房默认补齐AI。联机入口当前为本机/局域网创建与加入：房主创建房间，其他进程填房主地址加入（同机用127.0.0.1，UDP7779）；默认空位等真人，房主也可「补齐AI」。真人齐全或补齐AI后才能开始，只有房主可调人数与开始。当前云端仍是旧版，此轮没有启用公网大厅入口，也不要求现在复制服务器文件。

## 已实现的变化

### 界面与摄像机

- 标题、身份、三模式、训练等待房、对战等待房、设置、结算统一为居中1600×900设计框；画布按屏幕缩放，背景铺满。
- 角色卡、大头像、队伍座位及链路预览承担主要信息，移除原先一整条文字战斗栏。
- 生命放在右上：44px像素红心表示当前HP，灰空心表示损失；随枪械最大生命变化重建。护盾独立显示。右下展示武器/道具图、名称和E键，顶部显示计时/存活人数。
- 倒地显示个人复活倒计时。设置中的音效开关保留，镜头震动已停用。
- 相机LateUpdate直接跟随本地角色主体锚点（位置上方0.25单位），移除前瞻、平滑滞后、地图边缘钳制和偏移震动。视野中心跟随主体，包括倒地被拖动时；地图外延背景避免到边缘出现空白。

### 森林关卡

新增 `Forest_01 / 林间高台`，72×48世界单位。两侧低地出生，中央36×32高台，左右各上/中/下三段台阶。草地、土路、高台草色、台阶、崖边、石块、树桩和树林边界构成简洁分区，八蔬果与大枪保持原样。

高台是俯视2D地形：台阶可通行，其余崖壁作为真实障碍，同时影响角色、子弹、绳索与AI导航；没有桥下穿行、跳跃、射程/伤害加成或新增胜负条件。服务端同步Surface字段区分低地/高台/台阶。美术采用原生Sprite和静态几何分层，继续复用现有碰撞及关卡编辑器，没有引入新的地形插件。

主环境选用Ninja Adventure CC0素材；台阶、道路、草簇和界面底板为程序绘制，避免拉伸整张图块。来源、版本、校验和调整见[素材记录](FOREST_V3_ASSETS.md)。用户参考图仅用来分析构图，没有从图中拆取游戏资源。

### 复活、绳索与房间

- 正式对战删除复活区要求与显示，AI不再把倒地队友拖去复活点。
- 死亡开始计时，队伍仍有人活着，五秒后在身体当前位置复活。倒地身体保留绳链，可被拖动。若同帧团灭与复活到期，先判团灭/结算，避免凭空救活已全灭队伍。
- 复活保留原保护时间，主动攻击会结束保护；死亡清空枪、盾和持有道具的既有规则保留。
- 基础弹簧45→90、阻尼6→12、最大拉力100→200；主动移动加速度保留，静止制动降到2.5、物理阻力0.6。活队友和尸体质量均为1，使拖动实际发生。绳长、绕障碍连续路径和双方弹性强化×3保持原规则。
- 等待房人数切换会增删AI并重建链路；如果缩小后真人座位越界，拒绝缩小，先换位；连接正在分配座位时禁止重排。
- 断线转AI时可能仍到达旧输入包，现在按发送者/当前所有者、AI状态、输入轮次和序号过滤，避免所有权切换时报错。

### 关卡同学继续编辑

在 **Bound Shoot → Level Editor 关卡编辑器** 选择「林间高台」载入；摆放地面、障碍、枪械、道具与出生点后保存配置，停止并重新Play即可查看。新增forest主题、崖壁外观，保存/读取保留plateau结构；不再提供新放置复活区的工具。旧配置中的复活字段保留兼容但不参与战斗。

plateau的中心/尺寸/台阶负责外观和地表标记，实际封路取决于blocks中崖壁。改变高台轮廓时必须同步调整崖壁障碍与台阶缺口，保持视觉、导航和绳索一致。普通装饰地面没有碰撞，不能代替障碍。不要把森林关卡的旧原型复活区再作为玩法点位。
