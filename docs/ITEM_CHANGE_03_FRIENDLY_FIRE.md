# 道具修改第3条：友伤开关

2026-11-02，用户确认友伤规则，并授权与第4条一起实现。本条仅本地源码、Unity测试与文档，不构建、不部署、不提交/推送Git。

## 使用入口

停止Play，打开 **Bound Shoot → 数值编辑器 → 开启友伤**，点击“保存数值”，重新Play生效。配置字段为 `GameConfig.friendlyFire`，交付默认 **false（关闭）**。训练、本地AI与联机采用同一权威端规则；联机由主机/服务器配置决定，客户端不能自行绕过。此次未修改旧云端。

## 已确认的规则

| 条件 | 行为 |
|---|---|
| 关闭友伤 | 队友不掉生命/护盾、不受击退；子弹穿过队友 |
| 开启友伤 | 枪械、匕首、炸弹对队友造成100%配置伤害 |
| 开启后子弹碰到队友 | 子弹在该目标处结束，不继续穿透攻击后方敌人；枪口前的近距离判定一致 |
| 自己 | 不受自己攻击/炸弹伤害 |
| 队友护盾 | 正常优先吸收伤害；完全吸收仍可触发武器击退 |
| 复活保护 | 免疫友伤和击退；开启友伤时仍会阻挡命中的子弹，与敌人受保护时一致 |
| 击退 | 使用该武器的击退冲量，狙击默认6，其他默认0；炸弹未新增击退 |
| 战绩 | 友伤不增加攻击者伤害量、击杀数；被误杀者正常记录死亡 |
| 复活/结算 | 误杀与敌方击杀使用同一倒地、复活和团灭规则 |
| AI | 可能误伤队友，主动选敌仍只选择敌方 |

## 实现与验收

统一命中关系判断放在 `Scripts/Core/Models.cs` 的 `BattleRules.CanHit`；`BattleWorld`的枪口近距离命中、飞行子弹、匕首、炸弹全部使用该规则，`NetPlayer.Hurt`再执行自伤/友伤保护并仅为敌对命中计战绩。

在训练房增加伙伴，分别用狙击、匕首和炸弹测试关闭/开启开关；尤其检查伙伴站在敌人前面时子弹是否被挡住。测试自放炸弹不伤自己、复活保护不受伤，以及误杀不加击杀数。友伤会增加团队倒地风险，是否正式启用由用户在编辑器决定。

自动化结果与本轮报告统一记录在[第4条说明](ITEM_CHANGE_04_RANDOM_SUPPLIES.md)。第5条有限弹药/默认小刀尚未实施。
