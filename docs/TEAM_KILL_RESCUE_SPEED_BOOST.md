# 阵营击杀提示、救助和提速

右上角击杀提示分别按击杀者和被击杀者的阵营着色。蓝队名字为蓝色，红队名字为红色。本地和联机使用同一条服务器事件。

救助距离从 1.5 提到 1.7，可在关卡编辑器的「占点、救援与重生规则 → 救助距离」按地图调整。倒地角色的移动阻力从 0.6 调到 1.0，数值编辑器的「基础规则 → 倒地移动阻力」可修改。

原冲刺装置改名为提速道具，默认持续 4 秒。期间移动速度为 1.4 倍，连接使用者的绳索弹力和最大拉力为 1.35 倍。使用后仍由玩家控制移动方向，再次使用会重置持续时间。三个参数都在数值编辑器的「绳索道具与提速」中。

本次交付为本地源码。公网使用需要同步更新客户端和战斗服务器，以同步击杀事件的阵营和提速效果。
