# 第 8 条 火箭炮

2026-11-03 按确认方案实现。

| 参数 | 默认值 |
|---|---:|
| 最大射程 | 12 世界单位 |
| 飞行时间 | 0.8 秒 |
| 爆炸半径 | 2.5 世界单位 |
| 范围伤害 | 25 点，不随距离衰减 |
| 射击间隔 | 1.5 秒 |
| 弹药 | 5 发 |

在训练房武器区拾取火箭炮。选中武器格后，鼠标移动会显示抛物线和爆炸落点圈。超出射程时，落点限制在 12 单位内。如果落点位于墙内或地图外，沿原方向回退到有效位置。左键发射后火箭越过中途障碍物，落地时引爆。最后一发发射后装备切换为默认小刀，飞行中的火箭继续结算。

服务器根据输入的瞄准方向和距离计算落点，通过世界快照同步飞行状态。爆心与角色之间的实墙阻挡伤害。全局友伤开启时，队友承受完整伤害，发射者不受自己的火箭伤害。护盾及出生保护走通用伤害规则。AI 按预测落点决定能否命中。

关卡编辑器可放置固定火箭炮拾取点。三级随机物资池初始权重均为 0，可按关卡需要调整。数值编辑器可调整伤害、射程、间隔、弹药、飞行时间与爆炸半径。训练房共有 5 个武器拾取点和 10 个道具拾取点。

验收时可在训练房从障碍物一侧瞄准另一侧的靶子，确认先飞行再扣血。让另一靶子处于爆炸圈内但隔着实墙，确认该靶子免伤。连续打完 5 发检查弹药和小刀切换。
