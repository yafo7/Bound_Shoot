# 战斗 HUD 改版

以用户提供的新版像素 UI 图为参考。顶部居中放置链条比分牌，使用交叉剑和沙漏区分比分与剩余时间。右上角的红金边框面板显示心形图标、生命数值及按比例缩放的红色血条，护盾和救援状态显示在血条下方。

右下角用金角边框将四格道具栏和弹药信息放在一起，选中槽位使用金边和金色文字。拾枪时，武器详情出现在道具栏上方。设置与离开按钮放在左上角和左下角，使用带齿轮和门图标的浅色像素按钮。

布局用于正式对战、本地战斗、训练和联机热身。训练及热身期间，比分牌显示场地状态。边框和图标由 Unity UI 绘制，沿用现有心形、武器和道具精灵。

在隔离 Unity 工程通过 3 项 PlayMode 测试，覆盖训练 HUD 的弹药文本、战斗中返回主菜单以及退出连接。此次交付为本地源码。
